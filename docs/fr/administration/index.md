# Administration

Cette section s'adresse aux personnes qui déploient et administrent Xolo.

| Sous-section | Contenu |
| --- | --- |
| **[Installation & déploiement](./installation/index.md)** | Compiler ou déployer Xolo (binaire, image Docker), configurer les variables d'environnement, l'authentification et les plugins |
| **[Administration de l'organisation](./organisation/index.md)** | Gérer une organisation au quotidien : membres, rôles, budgets, fournisseurs LLM, modèles virtuels, middlewares, applications, paramètres |
| **[API de provisioning](./provisioning/provisioning.md)** | Piloter les organisations, membres et rôles depuis un système externe (plan de contrôle, opérateur, script), via une API dédiée en TLS mutuel |

> Pour comprendre les principes qui sous-tendent ces fonctionnalités (modèle de permissions, pipeline fournisseur → modèle → middleware, calcul des budgets…), consultez la section **[Concepts](../concepts/index.md)**.
